# Azure App Service Docs

External reference links for the Azure App Service hosting and deployment used by BookStore.

## Why these matter

BookStore is deployed manually to an Azure App Service Web App using `az webapp deploy`. These links cover the hosting plan, deployment options, and .NET Core configuration.

## Links

- [Azure App Service overview](https://learn.microsoft.com/pt-br/azure/app-service/)
- [Azure App Service .NET Core quickstart](https://learn.microsoft.com/pt-br/azure/app-service/quickstart-dotnetcore)
- [Deploy ASP.NET Core to Azure App Service](https://learn.microsoft.com/pt-br/aspnet/core/host-and-deploy/azure-apps/?view=aspnetcore-10.0)
- [Configure .NET Core in Azure App Service](https://learn.microsoft.com/pt-br/azure/app-service/configure-language-dotnetcore)
- [Azure App Service plans](https://learn.microsoft.com/pt-br/azure/app-service/overview-hosting-plans)
